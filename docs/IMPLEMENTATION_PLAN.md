# 第一阶段实施记录

采用已确认的项目交接说明，应用层使用 C11。先官方文件识别，再实现命令行工具；不展开麦克风、界面或 PCB。

- [x] 检查宿主机、虚拟机和下载完整性。
- [x] Windows 和 Ubuntu 官方示例验证。
- [x] 先写 WAV 输入测试，验证缺少实现时失败。
- [x] 实现 wav.c：RIFF 分块解析，限定 16kHz、单声道、PCM16、最长 60 秒，拒绝截断或异常长度。
- [x] 实现 asr.c：官方 C API、CPU、2 线程、中文、ITN，分别计时加载和识别。
- [x] 实现 main.c：参数检查、UTF-8 输出、文件保存（不覆盖已有文件）、退出码。
- [x] CMake 构建，单元测试、真实模型集成测试、错误输入验证。
- [x] Ubuntu 原生构建与官方样例复核，记录环境和未完成项目。
- [x] 中文 README、依赖来源与许可证、测试记录。
- [x] 用户个人录音转换与真实模型识别。
- [x] 用户确认首条录音开头未采集完整，重新录音后确认第二条识别文字正确。
- [ ] 录音工具的MP3解码警告仍需后续检查，不能宣称源文件完全无损解码。

接口：asr_demo --model-dir DIR --wav FILE [--output FILE] [--threads 1..8]。
输出文字到 stdout，耗时与诊断到 stderr。测试与模型文件分离。模型、依赖、构建产物不纳入源码版本管理。
