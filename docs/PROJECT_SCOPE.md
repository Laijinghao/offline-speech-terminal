# 项目范围与后续方向

暂定毕业设计题目：《基于嵌入式 Linux 的便携式离线语音转写终端设计与实现》。面向近距离、单人轮流讲话的普通话交流场景。

当前阶段：在电脑端Ubuntu完成离线录音文件转文字，应用代码采用C11，使用成熟预训练模型及正式C API，不自行训练识别模型。已在真实输入上验证采集文件、格式转换、识别与保存的完整流程。

应用模块：WAV输入检查与解析、识别引擎适配、命令行交互与文本保存。通过模型加载时间、识别耗时及RTF记录性能，不用一条成功样例声称整体准确率。

后续顺序：更多个人录音实验 → 麦克风采集与分段 → 目标Linux主板性能验证 → 屏幕和按键 → 自制扩展PCB和整机 → 对照实验与论文。

硬件候选为RK3566平台的香橙派3B、USB麦克风、HDMI屏幕以及自制接口扩展板，尚未购入或验证。电脑端成功不代表开发板性能达标。具体硬件形式、预算和近期技术迭代依据还需论证。

暂不包含翻译、多人同时讲话、声纹、大模型、云平台和模型训练。不承诺实时逐字字幕；可以先在一句话结束后显示结果。

贡献边界：语音模型属于上游成果，本项目工作集中于应用模块、接口整合、资源管理、设备部署、测试和硬件集成。后续改进必须用对照实验验证。
