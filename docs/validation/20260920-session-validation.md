# 多轮语音转写阶段验证记录

日期：2026-09-20。来源为用户提交的完整终端输出及 Ubuntu 两个会话的 metrics.tsv。运行环境为 Ubuntu 虚拟机，SenseVoice INT8、CPU 2 线程。数据不是 ARM 开发板实测。

## 验证结果

终端输出显示构建成功，原有 7 项测试通过；单独运行的会话集成测试报告单次模型加载、多轮真实推理、坏 WAV 恢复、输出不覆盖及输出失败恢复通过。真实麦克风两个会话共完成 11 轮，状态均为 ok；Ms8Sp8 会话明确展示了 q 退出流程。真人录音只验证功能运行，未提供逐字人工标注，不能据此宣称识别准确率或计算字符错误率。

RTF = decode_seconds / audio_seconds，以上按日志原始六位小数计算后显示三位小数。11 轮音频合计 239.098188 秒，解码合计 28.723749 秒，加权 RTF 为 0.120134（总解码 / 总音频）；这不是字符准确率，也不是同一音频重复实验的均值。

post_capture_seconds 包含读取 WAV、识别与保存 TXT，不包含首次模型加载。round_seconds 还包含等待按键及录音时间；I3jKQZ 第 6 轮为 307.079271 秒，其中音频 60 秒、录音后处理 8.240754 秒，不能写成识别耗时 307 秒。

## 文件与版本说明

Windows 本地 results/session_validation_20260920/ 保存两个会话副本、用户终端输出及派生 performance_summary.csv。Ubuntu 原录音目录保留，另存同名 results 归档。results/ 被 Git 忽略，个人音频及原始转写不纳入公开文档。

这两个历史会话以 metrics.tsv 为原始依据。当前源码已增加 summary.csv，但不能据此断言历史二进制也包含该功能；重新编译不会追溯生成历史 CSV。本次 performance_summary.csv 是归档时计算的派生表，不冒充程序当时生成的日志。
